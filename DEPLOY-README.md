# 🚀 TravelPilot PWA — Deploy in 60 Seconds

## What's in this folder:
- `index.html` — The main app
- `manifest.json` — PWA config (app name, icon, theme)
- `sw.js` — Service worker (offline support)
- `icon-192.png` — App icon (small)
- `icon-512.png` — App icon (large)

---

## 🟢 OPTION A: Netlify Drop (Easiest — No signup)

1. Open **https://app.netlify.com/drop** on your laptop
2. **Drag the entire `travelpilot-pwa` folder** onto the page
3. Wait 5 seconds — you get a URL like: `https://sunny-dolphin-abc123.netlify.app`
4. Share that URL with your team
5. Done! ✅

> To get a custom name: Sign up free → Site Settings → Change site name → `travelpilot.netlify.app`

---

## 🟡 OPTION B: GitHub Pages (Free, permanent)

1. Go to **https://github.com** → Sign up (free)
2. Click **"New Repository"** → name it `travelpilot` → Public → Create
3. Click **"Upload files"** → drag all 5 files from this folder
4. Commit changes
5. Go to **Settings → Pages → Source: main branch → Save**
6. Your URL: `https://yourusername.github.io/travelpilot`
7. Share with team ✅

---

## 🔵 OPTION C: Vercel (Free, fast)

1. Go to **https://vercel.com** → Sign up free with GitHub
2. Click "New Project" → Import your GitHub repo (from Option B)
3. Click Deploy
4. You get: `https://travelpilot.vercel.app`

---

## 📱 How your team installs it:

### iPhone (Safari):
1. Open the link in **Safari** (must be Safari, not Chrome)
2. A blue banner appears at the bottom: "Install TravelPilot"
3. Tap **Share ↑** (bottom center button)
4. Tap **"Add to Home Screen"**
5. Tap **Add**
6. TravelPilot icon appears on home screen — works like a native app!

### Android (Chrome):
1. Open the link in **Chrome**
2. A blue banner appears: "Install TravelPilot" → tap **Install**
3. OR tap the three dots ⋮ → "Install app" or "Add to Home Screen"
4. TravelPilot icon appears on home screen!

### Desktop (Chrome):
1. Open the link in Chrome
2. Click the install icon (⊕) in the address bar
3. Click "Install"
